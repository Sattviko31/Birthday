# Website Ulang Tahun ♥

## Kustomisasi
Buka `index.html`, edit blok `CFG` di bagian `<script>`: nama panggilan, tanggal jadian, umur, cerita, alasan, dan isi surat.

## Musik
Secara default musik berupa melodi piano sintetis (tanpa file). Untuk memakai lagu favoritmu, taruh file bernama `music.mp3` di folder ini (sejajar `index.html`).

## Deploy ke GitHub Pages
1. Buat repository baru di GitHub (mis. `birthday`).
2. Upload semua isi folder ini (`index.html`, `photos/`, `README.md`, dan `music.mp3` jika ada).
3. Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `(root)` → Save.
4. Tunggu 1-2 menit, situs tersedia di `https://USERNAME.github.io/birthday/`.
